# Библия за год

Прототип приложения для личного чтения Библии по годовому плану: отрывки внутри приложения, продолжение с первого непрочитанного места, отметки, закладки, размер шрифта, темы, резервные копии и сохранение библиотеки без интернета. Отметки хранятся в браузере; синхронизации между устройствами пока нет.

Встроены пояснения через официальный вход **Sign in with ChatGPT**. Доступность моделей и расходование лимитов зависят от аккаунта и правил OpenAI. При запросе пояснения выбранный отрывок и вопрос передаются OpenAI. Без интернета пояснения недоступны.

Это публикация собственного программного кода. Письма, данные личного кабинета, исходный PDF, извлечённый план, тексты библиотеки, личные отметки и данные доступа в репозиторий не включены. Поэтому новый checkout сам по себе ещё не содержит готового читательского приложения: сначала нужны данные плана и библиотеки.

## Проверки без личных данных и сетевых запросов

Нужен Node.js 22 или новее. Пакеты npm устанавливать не требуется.

```sh
npm test
```

Проверяются продолжение чтения, объединение резервных копий, границы отрывков между главами, PKCE и проверка подписи ID token, обработка незавершённых ответов ИИ, сохранение библиотеки при ошибках сети и квоты. Тесты используют искусственные данные и имитацию HTTP; они не обращаются к аккаунту ChatGPT и не заменяют проверки на телефоне.

## Подготовка данных

Импорт привязан к PDF-плану курса [«Исследуйте Писания»](https://izuchaem-bibliu.ru/biblia-za-god) и [библиотеке курса](https://lib.izuchaem-bibliu.ru/). Автоматическое извлечение таблицы из PDF не включено. Подготовьте локально каталог `source-cache` и два файла:

- `official-plan-rows.json` — массив из 365 строк таблицы. Каждая строка содержит `page` (номер страницы), `cells` (четыре строки: «День N», первое чтение Ветхого Завета, Новый Завет, второе чтение Ветхого Завета) и `cellSources` (четыре массива ссылок). Для каждого столбца чтения ссылки должны указывать одну книгу в формате `https://lib.izuchaem-bibliu.ru/#Код.Глава:1`; первая ячейка может иметь пустой массив ссылок. Это схема входа, а не прилагаемый план.
- `official-plan-metadata.json` — объект с полем `sha256`, содержащим SHA-256 исходного PDF. Вместо него можно положить сам исходный файл `official-reading-plan.pdf`; импорт сформирует метаданные.

Используйте достоверные назначения из источника и учитывайте права на материалы. Импорт содержит примечания к известным пропускам и опечаткам этого конкретного плана; он не подходит для другого плана без адаптации. В коде также сохранён вспомогательный парсер рассылки, но основной импорт использует таблицу PDF.

Нужен Python 3.10 или новее, без сторонних пакетов:

```sh
python prefetch.py
python import_data.py
node validate_data.mjs
```

Загрузка глав выполняется последовательно с кэшем и паузами. Первая команда требует интернет и обращается к библиотеке курса; выполняйте её только при допустимом использовании источника. Не включайте личную почту, ссылки входа или ссылки из личного кабинета в входные таблицы.

Результат: `dist/data/plan.json` и `dist/data/library.json`. Валидация проверяет весь год, уникальность отрывков, границы стихов, контрольную сумму библиотеки и известные особенности плана. Созданные данные и отчёты исключены из Git.

## Локальный запуск

После подготовки данных:

```sh
npm start
```

Откройте `http://127.0.0.1:8767/`. Для пояснений нажмите кнопку входа ChatGPT и завершите авторизацию в браузере. Для callback нужен свободный локальный порт 1457. API-ключ не требуется. OAuth-сессия находится только в памяти процесса; после перезапуска нужен новый вход. Файл `local-host-id.json` создаётся автоматически и не публикуется. Постоянное повторное использование выданной регистрации клиента пока не реализовано.

В настройках приложения можно сохранить библиотеку для чтения без интернета и выгрузить резервную копию отметок. Перед использованием на другом устройстве потребуется отдельно перенести резервную копию.

## Границы прототипа

`server/preview.mjs` — локальный сервер разработки, привязанный к `127.0.0.1`. Не публикуйте его через туннель, прокси или внешний сетевой интерфейс. В нём нет защиты отдельного публичного аккаунта владельца и постоянного защищённого хранилища OAuth-сессий. Ограничение запросов хранится в памяти и сбрасывается при перезапуске.

Для размещения на VPS нужны отдельная авторизация владельца, HTTPS, защищённое хранение и обновление сессии, повторное использование регистрации клиента и изоляция службы. Они не входят в этот выпуск. Публикация кода сама по себе не гарантирует доступ к подписке на любом сервере.

Официальная документация: [Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart), [приложения с открытым кодом](https://developers.openai.com/siwc/token-sharing-open-source), [собственная виртуальная машина](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms).

## Структура и лицензия

- `dist/` — интерфейс, модель отметок, service worker и собственные иконки.
- `server/` — локальный сервер, OAuth и потоковые пояснения.
- `import_data.py`, `prefetch.py`, `validate_data.mjs` — подготовка и проверка данных.
- `test_core.mjs`, `test_offline.mjs` — автономные проверки.

Собственный код и иконки распространяются по [MIT](LICENSE). Лицензия не распространяется на сторонний план курса и тексты Библии и не предоставляет доступ к чужим аккаунтам. Приложение не является официальным продуктом проекта «Исследуйте Писания» или OpenAI.
